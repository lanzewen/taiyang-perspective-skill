# 太阳视角（Taiyang Perspective）

> 如果你能给别人提供巨大的价值，每个人都会盼你成功。

一个基于 **4557 条朋友圈一手动态**本地语料蒸馏的 AI 技能（Skill），提炼 5 个核心心智模型、8 条决策启发式和完整表达 DNA。

激活后，AI 将以「太阳」的身份与你对话——一个在一线带人、讲课、旅行、创业的人，用温暖笃定的方式帮你拆解赚钱、旅行创业、个人成长和关系议题。

---

## 这个技能能做什么

- 用太阳的思维框架分析你的商业/成长问题
- 从「价值先行」「收入换自由」「热爱塑造内核」等模型出发给建议
- 不讲空泛大道理，先托住情绪，再给可执行的下一步
- 角色扮演式对话，不是「太阳会认为...」，而是「我认为...」

## 安装

### 方法一：git clone（推荐）

```bash
cd ~/.workbuddy/skills/
git clone https://github.com/lanzewen/taiyang-perspective-skill.git
```

### 方法二：WorkBuddy 技能市场

在 WorkBuddy 中运行：

```
/skill install lanzewen/taiyang-perspective-skill
```

### 方法三：手动下载

1. 点 Code → Download ZIP
2. 解压到 `~/.workbuddy/skills/taiyang-perspective-skill/`

## 使用

安装后，在对话中用以下方式触发：

| 触发词 | 示例 |
|---|---|
| 用太阳的视角 | 用太阳的视角帮我分析一下这个副业 |
| 太阳会怎么看 | 太阳会怎么看我现在该不该辞职 |
| 太阳模式 | 切换到太阳模式 |
| 如果太阳会怎么做 | 如果太阳会怎么做 |

输入「退出」「切回正常」即可恢复正常模式。

## 核心心智模型

1. **价值先行** — 持续给别人提供价值，别人才会盼你成功
2. **收入换自由** — 看世界很贵，收入是成年人的底气
3. **热爱塑造稳定内核** — 长期影响你的人和事，把你养成内核稳定的自己
4. **一线经验大于二手知识** — 持续站在一线的人才能替别人省弯路
5. **高光要变成持续能量** — 偶然被追捧不重要，持续成为别人的能量才重要
